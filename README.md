# Hack&Change — ПСБ legal assistant

Минимальный стартовый каркас для хакатона: загрузка базы знаний, простой поиск по фрагментам и генерация ответа через OpenAI-совместимый прокси организаторов.

## Быстрый запуск с демонстрационными данными

```bash
python3 solution.py
```

Если `DATA_DIR` не задан, скрипт ищет файлы в текущем каталоге. Для материалов из репозитория:

```bash
DATA_DIR=Данные python3 solution.py
```

Будет создан `submission.csv` с колонками `id,answer`. Без API-переменных скрипт работает в диагностическом режиме и записывает найденные источники.

## Запуск с API

```bash
export DATA_DIR=data
export LLM_BASE_URL="http://..."
export LLM_API_KEY="..."
export LLM_MODEL="..."
python3 solution.py
```

Ключи не должны попадать в Git.

## Ограничения первой версии

- поиск основан на пересечении слов;
- чанкинг пока построчный;
- нет BM25, embeddings, reranking и полноценной временной логики;
- UI и Docker будут добавлены следующим этапом.
